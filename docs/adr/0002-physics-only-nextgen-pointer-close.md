# Next-generation is physics-only; the close is a pointer close

Status: superseded by ADR-0003 for the next-generation DUNE weighting. The pointer close
and ~1 page remaining budget for the close itself still stand.

The live landscape already exceeds the chapter's $\sim 3$--$4$ page target, so the
remaining next-generation and global-fit-close subsections share a $\sim 1$ page prose
budget. Next-generation (DUNE then Hyper-Kamiokande, no subsection intro) states
baseline, detector type, and structural complementarity only: no exposure-indexed
sensitivities and no sensitivity figure. The close keeps the NuFIT~6.1 table, drops the
NuFIT plot, names the three open questions as pointers to existing long-baseline figures,
and hands off via a meantime bridge to NOvA's leading-direct $\Delta m^{2}_{32}$
disappearance measurement. This was chosen over a mini sensitivity review so a later pass
cannot “complete” the section with DUNE or Hyper-K numbers without blowing the budget.
